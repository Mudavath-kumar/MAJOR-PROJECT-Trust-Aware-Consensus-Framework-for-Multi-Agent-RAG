# Candidate v4 AI-assisted review

This is a separate, non-human review artifact for the 200-record TrustRAG candidate. The original candidate and its pending human-review fields are preserved. Decisions are AI-assisted provisional judgments grounded in the frozen source-linked evidence export and existing structural audit. They are not human approvals, independent adjudication, or a paper-eligible frozen snapshot.

The review found eight unanswerable records whose scoped evidence is sufficient to answer, and one false-premise record requiring an explicit abstention-label policy. These records are not silently corrected: they remain in the original dataset and are flagged here. All 200 human review statuses remain pending. See `ai-review-decisions.csv` for the decision, record-specific reason, evidence IDs, and reviewer type for every example.
